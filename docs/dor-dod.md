# Definition of Ready (DoR)
*A task só será iniciada se atender aos seguintes pontos:*
- [ ] Regras de negócio detalhadas.
- [ ] Dados, tipos e validações definidos.
- [ ] Mensagens de sistema (erro/sucesso/aviso) mapeadas.
- [ ] Esboço da interface (UX/UI) criado.
- [ ] Fluxos de dados definidos.
- [ ] Critérios de aceite definidos.

# *Definition of Done (DoD)
*A história só será considerada entregue se:*
- [ ] Código revisado.
- [ ] Estiver dentro de todos os padrões do projeto.
- [ ] Mergeado na branch `dev`.
- [ ] Testes executados sem falhas.
- [ ] Documentado.
- [ ] Critérios de aceite validados.
