# Requisitos do Projeto

**Parceiro:** GSW

---

## Requisitos funcionais

| ID | Descrição |
|----|-----------|
| RF01 | O sistema deve permitir que o usuário defina seu objetivo de aprendizado/desenvolvimento de habilidade. |
| RF02 | O sistema deve apresentar uma jornada/trilha guiada por um "mentor" virtual, personalizada conforme o objetivo do usuário. |
| RF03 | O sistema deve propor atividades ou missões ao usuário, alinhadas ao seu nível e objetivo. |
| RF04 | O sistema deve registrar e acompanhar o progresso do usuário ao longo da jornada. |
| RF05 | O sistema deve fornecer feedback personalizado sobre o desempenho e a evolução do usuário. |
| RF06 | O sistema deve implementar mecânicas de gamificação, incluindo XP/pontos, níveis de progressão, conquistas e sequência de estudos. |

---

## Requisitos Não Funcionais (RNF)

| ID | Descrição |
|----|-----------|
| RNF01 | O projeto deve possuir um Manual de Instalação. |
| RNF02 | O projeto deve possuir um Manual do Usuário. |
| RNF03 | O projeto deve conter documentação da API e dos principais endpoints/integrações. |
| RNF04 | A aplicação deve tratar indisponibilidade ou esgotamento da cota de IA sem impedir o uso das funcionalidades que não dependem dela. |
| RNF05 | O sistema deve registrar e controlar o consumo de IA, incluindo a quantidade de chamadas e, quando disponibilizado pelo provedor, a quantidade de tokens utilizados. |
| RNF06 | O sistema deve implementar ao menos uma estratégia de redução de consumo de IA. |
| RNF07 | O sistema deve manter apenas as últimas interações relevantes e uma memória resumida (com objetivo, nível, dificuldades e resultados do usuário), evitando reenviar todo o histórico para a IA. |
| RNF08 | O sistema deve aplicar técnicas de PLN para identificação das etapas de um pipeline de PLN e seleção de corpora de texto para treinamento e validação. |
| RNF09 | O sistema deve aplicar ferramentas de inteligência artificial e matemática computacional na resolução dos problemas de PLN do projeto. |
| RNF10 | O desenvolvimento deve empregar metodologias que garantam critérios de qualidade da solução computacional. |
| RNF11 | A solução deve ser adaptável aos diversos meios de hospedagem (compartilhado, cloud, VPS, colocation, servidor dedicado), utilizando o recurso adequado a cada um. |
| RNF12 | O sistema deve ser implantado considerando a melhor performance na infraestrutura de rede de computadores disponível. |
| RNF13 | O sistema deve permitir que o núcleo do assistente seja adaptável a outros domínios/contextos sem exigir reconstrução completa da aplicação. |
